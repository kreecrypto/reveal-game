# Reveal Game

Cute Arcade reveal-image web game.

## Stack
- GitHub: source of truth
- Vercel: frontend production
- Cloudflare Worker: API
- Cloudflare D1: game/session data
- Cloudflare R2: uploaded game assets

## Frontend
Static `index.html` is deployable directly to Vercel.
